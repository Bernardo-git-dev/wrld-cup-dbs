# World Cup Database - freeCodeCamp Project

Este é um projeto de banco de dados relacional usando PostgreSQL, exigido pelo curso do [freeCodeCamp](https://www.freecodecamp.org/).

## 📁 Estrutura

- `worldcup.sql`: Criação das tabelas e inserção dos dados.
- `queries.sql`: Consultas SQL que resolvem os desafios do projeto.

## 🧪 Como executar

1. Certifique-se de ter o PostgreSQL instalado.
2. Crie o banco com:
   ```bash
   createdb worldcup
